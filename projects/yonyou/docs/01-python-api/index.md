## 这个模块最终要完成什么

把普通应收查询函数逐步接成一个可调用的小服务：能约定输入输出、处理失败、调用外部接口，并按场景返回完整结果或持续发送结果。使用同一组合成业务数据持续演进，重点理解每次新增要求带来的代码变化。

默认已有函数、字典、`return` / `print` 与 SQL 基础。基础复习按需查阅，主要时间用在类型约定、工程组织、异步执行和接口衔接。总览中的约 22 小时作为初始预算，实际随阅读与练习调整。
