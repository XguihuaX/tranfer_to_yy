# 03 LLM调用、LangChain与工具使用

本模块先学LLM、LangChain与Agent的通用知识：模型怎样调用，消息怎样组织，输出怎样校验，工具怎样执行，框架怎样安排下一步。重点是理解机制、读懂AI写出的代码，以及知道操作和排错的步骤。

示例服务于这些知识。连续代码使用一个小型客户余额查询，便于前后对照；你只需把它当作“按编号查询一条记录”，无需先学财务术语或搭建ERP。主题适合时，也用天气、计算和资料查询理解同一个机制。操作按需实做。

## 同一个例子怎样逐步长出来

开始只有一个问题，之后加入消息与结构化意图，再把普通Python函数包装成工具，观察执行循环，最后用LangChain组织多工具Agent。连续例子中，C001查询结果为12800，C002为0，C003为500；找不到编号与查到零分开处理，名称不唯一时先询问。学习重点是输入、输出与分支怎样连接。

这些步骤能迁移到其他任务：天气工具接收城市并返回实时数据；计算工具接收数字并返回计算结果；资料查询接收关键词并返回匹配内容。它们的数据不同，但“模型生成参数→程序执行→回填结果→继续回答”的路线相同。

配套文件在`learning/03-llm-tools/lab/`，各章给出相关完整代码或文件位置。共享配置与业务函数保持一致。LangGraph持久化、人工介入和工作流在05模块深入；04模块承接RAG与业务数据接入。
