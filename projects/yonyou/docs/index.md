这套教材围绕“在 ERP 基础上开发、部署和交付 AI 应用”展开。每章先准备正文、例子与练习，再结合对话答疑逐步学习。

!!! tip "从这里开始"
    产品业务与技术主线并行。首次阅读可从 [00-01 认识 ERP](00-products/01-what-is-erp.md) 和 [01-01 跟着数据读懂 Python 函数](01-python-api/01-reading-python.md) 开始。已完成01阅读后，可进入 [02 Linux、Git 与部署](02-deployment/index.md)：九章正文已准备并通过作者检查与总对话二次复核，按自己的节奏阅读和提问。

## 如何阅读和提问

1. 在左侧目录选择当前模块和章节，沿章内目录阅读。
2. 遇到问题，回到对应学习对话，用章节和小节定位，例如“00-01 第二节：ERP 和接口是什么关系”。不记得编号也可以直接问。
3. 答疑会补回相关小节或章末答疑；跨章内容先记下来，主线回到原位置。
4. 练习结果记录在模块进度里。教材写好不代表你已经掌握，不要求每次从聊天记录找正文。

## 持续使用的例子

我们用合成数据构建一个小型“ERP 应收查询助手”：理解用户要查什么，补齐查询条件，读取模拟 ERP 数据，返回金额与依据，再逐步加入工具、工作流和部署。

产品业务解释这项任务为什么这样做；技术章节逐步实现它。具体用友产品、内部技术栈和第一份客户任务尚未确认，不把练习系统等同于实际 ERP。

## 本手册的约定

- 当前学习者会 SQL，有 AI Coding 项目经验，需要补代码独立维护、Linux 与 Docker；不会 Java。
- 技术主线采用 Python；Java 的深入学习等待岗位实际要求。
- 每章只覆盖清楚界定的主题，必要的拓展放入后续章节。
- 用友产品和框架能力以官方资料核实；模拟案例会明确假设。
- 右上方搜索可查找术语，章节代码支持复制；折叠答案可在练习后查看。
