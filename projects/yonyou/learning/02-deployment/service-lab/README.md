# 02 查询服务练习

Python 3.9+，仅标准库。使用合成应收余额：截至 2026-10-31，C001 有效应收 20000 元、已核销收款 7200 元，未收 12800 元；C002 未收为 0，均为 CNY，无其他调整。

在本目录执行 `QUERY_CURRENCY=CNY python3 server.py`。另一个本机终端执行 `curl -i http://127.0.0.1:8028/receivables/C001`，预期 HTTP 200 和金额 12800；C999 返回 404。`/health` 返回进程响应状态，不检查数据文件。

默认 HOST=127.0.0.1、PORT=8028。Ctrl-C 停止前台程序。日志写到标准错误。数据路径绑定于 server.py 所在目录。

这是学习运行、版本管理和排障的单进程服务，没有登录认证，不用于直接对外生产托管。Docker 练习的主机端口默认 8029，Compose 内部端口 8028；按 02-09 的环境前提执行。
