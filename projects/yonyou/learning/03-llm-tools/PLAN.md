# 03 教材编写落实

2026-11-08，总对话依据本轮用户授权准备整个模块。组织方式是知识补充、代码阅读、操作步骤与必要排障；每章完整正文先于教学。

章序：模型调用/PyCharm → 消息/模板/上下文 → 结构化输出/业务校验 → 工具定义/手动循环 → LangChain Agent → 运行控制/排障 → 代码审查/小规模验证 → MCP基础选读。

每章包含问题、前置、核心机制、连续示例、相关完整源码、操作步骤、误区、可选练习/折叠答案、回顾、来源与后续。复杂源码可折叠，核心解释保留在正文。用户可以先读或推演，实操不是通关条件。

教学优先级更新：用户要求先学，不必完全适配ERP。模型、消息、结构化输出、工具循环与Agent为通用主线，连续查询代码只用于观察执行过程。可使用天气、计算器、文件与资料查询帮助迁移；财务术语不是前置，不增加ERP项目建设要求。

保留示例的最小数据假设：同一组织、CNY、截至2026-11-08。C001有效应收20000、已核销7200；C002为8000/8000；C003为500/0，余额12800/0/500。海星名称片段匹配两客户；未知客户不补零。真实权限与ERP接入不在例子中假装实现。

主线LangChain及标准兼容集成，Pydantic验证；LiteLLM按需对照。MCP2.3用MCPServer/Client，未混用旧FastMCP。LangChain新MCPAdapter为beta且有额外依赖，先讲清接回步骤，独立实验不冒充完整模型集成。

核对：固定版本安装；本地模拟HTTP验证模型相关脚本、结构、工具、Agent和失败路径；本机MCP子进程实际连接；严格构建、链接/锚点、折叠答案与网页抽查。真实模型及Windows未实测的范围单独记录。
