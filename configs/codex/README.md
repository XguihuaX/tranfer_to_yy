# 全局 AGENTS.md 两段规则

`AGENTS-fragment.md` 原样摘自旧电脑的 `~/.codex/AGENTS.md`，只含用户要求迁移的两节：

- 决策与执行原则
- 主张、边界与预设质疑

用户已于 2026-11-09 明确要求把这两段带到新电脑。新电脑上的 Codex 执行迁移时，将这两段合并到其实际使用的用户级 `AGENTS.md`；先检查用户目录及是否设置了自定义 Codex 配置目录，不照搬旧 Mac 的绝对路径。

若目标文件不存在，创建文件并写入片段；若已存在，先保留备份，再合并这两节。已有相同内容时不重复追加，保留其他不相关规则。若同名小节已存在但内容不同，对照并说明差异，再按用户最新要求处理。

完成后重新读取目标文件，确认两节内容完整，记录实际文件路径和合并结果。生效情况在新会话中核对。

用友项目自身的 `AGENTS.md` 另在 `projects/yonyou/AGENTS.md`，其中是教学协作规则。不要用项目文件覆盖全局文件，也不要用此全局片段覆盖项目文件。
